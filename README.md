# Empire Clicker 👑

Браузерная игра-кликер: монеты, улучшения, боссы, 200 достижений, магазин, сезоны рейтинга, кланы и админ-панель.

## Что где лежит

| Путь | Назначение |
|---|---|
| `public/index.html` | игра (разметка и код) |
| `public/style.css` | **стили игры** (отдельный файл) |
| `public/admin.html`, `public/admin.css` | админ-панель и её стили |
| `public/config.js` | **адрес сервера**, единственный файл, который нужно править для подключения |
| `public/sw.js`, `manifest.webmanifest`, `icon-*.png` | установка на экран телефона |
| `server/index.mjs` | свой сервер (API, хранение в файлах) |
| `netlify/functions/api.mjs`, `netlify/lib/` | код API (общий для своего сервера и Netlify) |
| `.github/workflows/pages.yml` | автоматическая публикация на GitHub Pages |
| `user.json` | начальная база пользователей (необязательно) |
| `tools/make-hash.mjs` | генератор хеша пароля администратора |

## Важно про GitHub

**GitHub Pages размещает только статические файлы.** Серверный код на нём не работает, поэтому аккаунты, рейтинг, кланы, облачные сохранения и админка там сами по себе недоступны. Есть три варианта:

### Вариант 1. Только GitHub Pages (без сервера)
Игра работает в браузере: клики, улучшения, боссы, магазин, достижения, сохранение в браузере. Нет аккаунтов, рейтинга, кланов и админки. Ничего настраивать не нужно, в `public/config.js` стоит `window.EC_API = null`.

1. Загрузите всё содержимое этой папки в репозиторий GitHub (ветка `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Откройте вкладку **Actions**, дождитесь зелёной галочки. Сайт будет на `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Все пути в игре относительные, поэтому она работает и в подпапке репозитория.

### Вариант 2. GitHub Pages + свой сервер (всё работает)
Игра остаётся на GitHub Pages, а API запускается отдельно:

1. Разверните сервер на любом хосте с Node.js 18+ (Render, Railway, Fly.io, VPS):
   ```bash
   npm install
   npm start
   ```
   или через Docker: `docker build -t empire . && docker run -p 3000:3000 -v empire-data:/data -e ADMIN_PASSWORD=ваш_пароль empire`.
2. Задайте на сервере переменные (см. раздел «Пароль админки» ниже): `ADMIN_PASSWORD`, при желании `ALLOWED_ORIGIN=https://ВАШ-ЛОГИН.github.io`.
3. В репозитории GitHub: **Settings → Secrets and variables → Actions → Variables → New repository variable**, имя `EC_API_URL`, значение: адрес сервера, например `https://empire-api.onrender.com` (без слэша в конце).
4. Запустите публикацию снова (Actions → Deploy to GitHub Pages → Run workflow). Адрес попадёт в `config.js` сам.

Данные игроков лежат в папке `DATA_DIR` (по умолчанию `./data`). **Эта папка должна быть на постоянном диске**, иначе при перезапуске хоста данные пропадут (на бесплатных тарифах Render и подобных диск часто временный; подключите Persistent Disk или Docker-том `/data`). Копии базы сервер делает сам раз в сутки (7 последних, раздел «Безопасность» в админке).

### Вариант 3. Всё на одном сервере
Запустите `npm start`, сервер сам раздаёт и игру, и API. В `config.js` поставьте `window.EC_API = '';` (тот же адрес).

## Пароль админки

**Пароль администратора нигде не хранится в коде**, поэтому его нельзя достать из исходников. Он задаётся переменной окружения **на сервере** (на GitHub Pages админки нет, она живёт вместе с API):

- `ADMIN_PASSWORD`: пароль (точки и любые символы входят в пароль).
- Надёжнее: `ADMIN_PASSWORD_HASH` вместо пароля, хеш делается командой `npm run hash`.
- `ADMIN_TOTP_SECRET`: двухфакторный вход (код из Google Authenticator, секрет в base32).
- `ADMIN_IPS`: список разрешённых IP через запятую.
- `ADMIN_FORCE_ENV=1`: если забыли пароль, сменённый в панели, этот флаг включает пароль из переменных.

Пока пароль не задан, вход в админку закрыт. Никогда не записывайте пароль в файлы репозитория (даже в частном репозитории). После 5 неверных попыток вход блокируется на 15 минут.

Открыть панель: в игре «Профиль» → в самый низ → «🛡 Админ-панель», либо страница `admin.html`.

## Переменные сервера

| Переменная | Значение |
|---|---|
| `PORT`, `HOST` | порт и адрес (по умолчанию 3000 и 0.0.0.0) |
| `DATA_DIR` | папка данных (по умолчанию `./data`) |
| `ALLOWED_ORIGIN` | с какого сайта разрешены запросы (по умолчанию любой) |
| `SERVE_STATIC=0` | не раздавать игру, только API |
| `TRUST_PROXY=1` | если сервер стоит за прокси (настоящие IP для защиты от перебора) |
| `ADMIN_PASSWORD`, `ADMIN_PASSWORD_HASH`, `ADMIN_TOTP_SECRET`, `ADMIN_IPS` | см. выше |

## Что умеет игра

- **200 достижений** с фильтрами и кнопкой «Забрать все», календарь входа на 30 дней, задания дня.
- **Боссы** шести типов, золотые монеты, комбо до ×3, критические удары, питомец, перерождения.
- **Магазин:** сундуки, ускорители, скины, премиум-карты (оплата демо).
- **Рейтинг** по балансу и недельные **сезоны** с призами, **кланы**.
- **Защита рейтинга:** сервер проверяет скорость кликов, баланс и скачки заработка, подозрительных скрывает до проверки. Это эвристики, не абсолютная защита.
- **Админка:** игроки, экономика (множители, события, скидки), рассылки, подарки и предметы, достижения, воронка и удержание, резервные копии.
- **Установка на телефон** (PWA), уведомления пока игра открыта в фоне, музыка и громкость.

## Netlify (если понадобится)

Проект по-прежнему работает на Netlify: подключите репозиторий, настройки подтянутся из `netlify.toml`, переменные окружения задаются в Site configuration → Environment variables, в `config.js` стоит `window.EC_API = '';`.
