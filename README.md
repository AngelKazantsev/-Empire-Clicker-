# Empire Clicker 👑 — версия для Netlify

Сервера запускать не нужно: игра лежит на Netlify и работает сама.
Регистрация, облачные сохранения и общий рейтинг хранятся в Netlify Blobs (встроенное хранилище Netlify, ничего настраивать не надо).

## Как выложить (3 минуты, через GitHub)

1. Создайте на github.com новый репозиторий и загрузите в него **все файлы из этой папки**
   (кнопка «Add file → Upload files», перетащите содержимое архива).
2. На app.netlify.com нажмите **Add new site → Import an existing project → GitHub** и выберите репозиторий.
3. Настройки подтянутся из `netlify.toml`. Нажмите **Deploy**. Через минуту сайт будет по адресу вида `https://что-то.netlify.app`.

Каждое обновление файлов в репозитории автоматически обновляет сайт.

### Другой способ — через командную строку
```bash
npm install -g netlify-cli
npm install
netlify login
netlify init        # создать сайт
netlify deploy --prod
```

> Важно: загрузка папки перетаскиванием на netlify.com/drop **не подойдёт**. Там размещаются только статические файлы, а для регистрации и рейтинга нужна функция из папки `netlify/functions`.

## Что где лежит

| Путь | Назначение |
|---|---|
| `public/index.html` | сама игра |
| `netlify/functions/api.mjs` | сервер: регистрация, вход, сохранения, рейтинг |
| `netlify.toml` | настройки сборки |
| `user.json` | начальная база пользователей (импорт и бэкап) |
| `package.json` | зависимость `@netlify/blobs` |

## Как работает

- **Регистрация и вход:** логин (латиница, цифры, `_`), ник и любой пароль. Пароль хранится только как хеш scrypt с солью, сессия живёт 30 дней.
- **Уникальный ID:** у каждого игрока свой ID из 8 символов, он виден в рейтинге.
- **Сохранения:** игра отправляет прогресс на сервер каждые 15 секунд и при закрытии вкладки. На другом устройстве прогресс подтягивается после входа.
- **Рейтинг:** число монет на балансе берётся из хранилища, топ-50 обновляется на вкладке «Профиль». Рейтинг пересчитывается не чаще раза в 20 секунд.
- **Гость:** можно играть без аккаунта, прогресс остаётся в браузере.

## База пользователей user.json

Файл `user.json` лежит в корне проекта и служит **начальной базой**. На Netlify нельзя дописывать файлы во время работы сайта, поэтому живые данные игроков хранятся в Netlify Blobs, а `user.json` работает так:

- **Загрузка:** при каждом новом деплое функция читает `user.json` и добавляет в базу тех, кого там ещё нет. Формат записи:
  `{"username": "vasya", "password": "любой пароль", "nick": "Вася", "tot": 0}`.
  Пароль из файла сразу превращается в хеш. Вместо `password` можно указать готовые `salt` и `hash`.
- **Выгрузка (резервная копия):** задайте в Netlify переменную окружения `ADMIN_KEY` (Site configuration → Environment variables), затем откройте
  `https://ваш-сайт.netlify.app/api/admin/export?key=ВАШ_КЛЮЧ`. Скачается готовый `user.json` со всеми игроками, их очками и хешами паролей.
  Добавьте `&full=1`, чтобы выгрузить ещё и полные сохранения игр.
- **Перенос или восстановление:** положите выгруженный файл вместо `user.json` в репозитории и задеплойте сайт.

Не публикуйте в открытом репозитории файл с паролями открытым текстом: для публичных репозиториев используйте выгрузку с хешами.




## Дизайн и награды

- **Дизайн:** тёмно-фиолетовый с розовым акцентом (скин «Сакура»). Пять вкладок: Кликер, Улучшения, Магазин, Награды, Профиль. Валюта: монеты ♛.
- **200 наград** на вкладке «Награды»: клики, деньги, улучшения (по каждому отдельно), боссы (по каждому типу), крит-удары, золотые монеты, питомец, перерождения, серия входов, скины, сундуки, покупки, время в игре и другие. Есть фильтры по категориям и кнопка «Забрать все». Готовые награды всегда наверху, полученные уходят вниз.
- **Календарь входа** на 30 дней с большими наградами на 7, 14, 21, 28 и 30 день.
- **В админ-панели:** в карточке игрока блок «Достижения (200 наград)»: выдать награды всей категории или сразу все, а также сбросить достижения.

## Магазин 🛒

Вкладка «Магазин» на главном экране игры:

| Раздел | Что внутри |
|---|---|
| Сундуки | обычный, редкий и легендарный: случайные деньги, билеты, ускорители, шанс на скин |
| Ускорители | ×3 к доходу, турбо-автоклик (+5 кликов/сек), мгновенный бонус ×2 |
| Скины | 8 цветовых тем оформления |
| Премиум-карты | Gold, Platinum, Black с бонусом к доходу и клику (оплата демо) |
| Билеты | пакеты на 5, 15 и 40 штук (оплата демо) и ускорители за билеты |

**В админ-панели:**
- *Пользователи → карточка игрока → «Предмет магазина»* и окно «Начислить игроку» позволяют выдать любой сундук, ускоритель, скин или премиум-карту. Можно указать количество.
- *Бонусы → Подарок всем* и *Сообщения → Рассылка* тоже умеют прикладывать предмет, его получат все игроки.
- *Экономика → «Скидка в магазине»* ставит скидку до 90% на всё за игровые доллары. Игроки видят баннер и зачёркнутые цены в течение 30 секунд.

## Админ-панель 🛡

**Как открыть:** в игре зайдите во вкладку «Профиль», прокрутите в самый низ и нажмите «🛡 Админ-панель». Введите пароль `.xxx777.` (точки в начале и в конце входят в пароль). Панель откроется поверх игры. Её можно открыть и отдельной страницей: `https://ваш-сайт.netlify.app/admin.html`.

**Безопасность:** пароль проверяется только на сервере, в коде страницы его нет. После 6 неверных попыток вход блокируется на 10 минут. Сессия админа живёт 12 часов.
Обязательно смените пароль: «Безопасность → Изменить пароль» в самой панели, либо задайте переменную окружения `ADMIN_PASSWORD` в настройках Netlify.

**Что умеет панель**

| Раздел | Возможности |
|---|---|
| Главная | число игроков, онлайн, новые за сутки, общий доход, графики, топ-5, быстрые действия |
| Пользователи | поиск и фильтры, карточка игрока: начислить или установить баланс, билеты, сменить ник и пароль, написать лично, заблокировать, сбросить прогресс, удалить |
| Экономика | сумма балансов, распределение, **множители** (доход за клик, пассивный доход, цены улучшений для всех игроков), глобальное событие ×N, подарок всем |
| Статистика | клики, уровни, перерождения, состояние сервера |
| Бонусы | подарок валютой и билетами всем игрокам |
| События | запуск и остановка множителя дохода на заданное время |
| Сообщения | рассылка всем игрокам, игроки видят её в игре |
| Настройки | открыть или закрыть регистрацию, **технические работы** (заставка в игре у всех), автообновление, тема |
| Безопасность | смена пароля, завершение других сессий, журнал действий администратора |

Изменения доходят до игроков в течение 30 секунд, пока они играют. Заблокированного игрока выкидывает на экран входа.

## Посмотреть данные

В панели Netlify: **Site → Blobs**. Там хранилища `users`, `sessions`, `saves`, `lb`, `meta`.

## Ограничения

- Рейтинг можно подделать запросом к API, потому что очки присылает сама игра. Для честных соревнований доход нужно пересчитывать на сервере.
- Рейтинг рассчитан на сотни и тысячи игроков. Для десятков тысяч лучше перейти на полноценную базу (Supabase, Neon).
- Ограничение попыток входа работает в пределах одного экземпляра функции, это базовая защита.
- Объёмы и лимиты бесплатного тарифа смотрите на netlify.com/pricing.
